# 选择接入方式

在 Python 应用里运行 DataAgent，或为现有 Agent 增加工具与流程。

| 你要做的事 | 从这里开始 |
| --- | --- |
| 在 Python 进程内发起对话、指定输入和产物 | [Python SDK 指南](sdk.md) |
| 查询公开 SDK、宿主或低层接口 | [Python API 参考](../../reference/python-api.md) |
| 选择并编写插件、工具、Skill、Hook 或子代理 | [扩展指南](extensions/overview.md)和[扩展声明参考](../../reference/extension-schema.md) |
| 连接外部 MCP 服务 | [MCP 接入](extensions/mcp.md)和[配置参考](../../reference/mcp-configuration.md) |
| 配置模型、工作区和会话 | [配置操作](../configuration.md)和[会话与产物](../sessions-and-outputs.md) |
| 从其他进程调用 DataAgent | [REST API](../../reference/rest-api.md)、[AG-UI 接入](../../reference/agent-runtime.md)或 [A2A](a2a.md) |

[示例目录](../../../../examples/README.md)包含可运行的配置、插件和本地 MCP 服务。修改运行时源码时，从[开发者文档](../../../development/index.md)进入。
