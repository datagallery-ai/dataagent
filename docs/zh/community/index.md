# 社区

在这里选择提问、反馈、贡献或分享可复现的案例。

<a name="feedback"></a>

## 联系与反馈

| 要做什么 | 去哪里 | 带上哪些信息 |
| --- | --- | --- |
| 提问或反馈缺陷 | [GitHub Issues](https://github.com/datagallery-lab/datafoundry/issues) | 版本或提交、环境、预期和实际结果、复现步骤，以及必要的脱敏日志或 Trace |
| 建议功能或数据源 | [GitHub Issues](https://github.com/datagallery-lab/datafoundry/issues) | 用户角色、工作流、涉及的数据和当前行为，以及期望结果 |
| 分享可复现场景 | [提交案例](scenario-cases.md) | 可公开的输入、操作步骤和能验证的结果 |

提交前先搜索已有问题。适用时说明能否在 `main` 复现。已公开的安全通告见 [GitHub Security Advisories](https://github.com/datagallery-lab/datafoundry/security/advisories)。

<a name="contributing"></a>

## 参与贡献

修改文档、源码、连接器或测试时，按[仓库贡献指南](../../../CONTRIBUTING.md)准备提交和验证。启动本地环境和选择测试见[开发者文档](../../development/index.md)。

<a name="sharing-materials"></a>

## 分享材料

- 区分已实现行为、实验和提案，写明可验证的版本。
- 提供其他维护者可以独立复查的材料。分享前脱敏日志和截图，必要时使用小规模合成数据。
- 公开渠道请省略凭据、客户记录、专有数据、私有 Trace 和未公开漏洞细节。
