# 联系与反馈

| 需求 | 去哪里 | 需要包含 |
| --- | --- | --- |
| 提问或反馈缺陷 | [GitHub Issues](https://github.com/datagallery-lab/datafoundry/issues) | 版本或提交、环境、预期和实际结果、复现步骤，以及脱敏后的日志或 Trace。 |
| 建议功能或数据源 | [GitHub Issues](https://github.com/datagallery-lab/datafoundry/issues) | 用户角色、工作流、涉及的数据、预期结果及当前行为的缺口。 |
| 修改文档、代码或示例 | [参与贡献](contributing.md) | 按贡献流程准备提交与验证。 |
| 分享场景 | [场景案例指南](scenario-cases.md) | 准备其他人可复现的工作流和可公开的输入。 |

新建 Issue 前先搜索已有记录。适用时附上是否能在 `main` 复现。

已公开的安全通告见 [GitHub Security Advisories](https://github.com/datagallery-lab/datafoundry/security/advisories)。请在公开 Issue 中省略漏洞细节和私有数据。分享日志和截图前阅读[协作原则](collaboration-policy.md)。
