# Contact and feedback

| Need | Where to go | What to include |
| --- | --- | --- |
| Ask a question or report a bug | [GitHub Issues](https://github.com/datagallery-lab/datafoundry/issues) | Version or commit, environment, expected and actual results, reproduction steps, and relevant redacted logs or traces. |
| Suggest a feature or data source | [GitHub Issues](https://github.com/datagallery-lab/datafoundry/issues) | Who needs it, their workflow, the data involved, expected results, and the gap in the current behavior. |
| Change docs, code, or examples | [Contributing](contributing.md) | Follow the contribution checklist. |
| Share a scenario | [Scenario guide](scenario-cases.md) | Prepare a workflow and demo-safe inputs that others can reproduce. |

Search existing issues before opening a new one. If applicable, include whether you could reproduce the issue on `main`.

For published security notices, see [GitHub Security Advisories](https://github.com/datagallery-lab/datafoundry/security/advisories). Keep vulnerability details and private data out of public issues. See the [collaboration policy](collaboration-policy.md) before sharing logs or screenshots.
