# Product overview

DataAgent turns a natural-language question into a data analysis task with visible progress, inspectable results, and saved outputs.

## What you can do

After configuring a model, ask in the browser or the terminal. The Server uses the selected configuration and enabled extensions, and streams its reply. To supply local files, set up [data inputs](../guides/inputs.md). See [sessions and outputs](../guides/sessions-and-outputs.md) to find the results.

## Entries

- Review conversations, sessions, and outputs in the browser with the [Web workbench](../guides/web.md).
- Access the same runtime over SSH or from a terminal with the [TUI](../guides/tui.md).
- Call or extend the runtime from an application through [integration and extension guides](../guides/integrate/index.md).

## Boundaries

Database queries use an enabled plugin configured for the data source. See the [capabilities matrix](capabilities.md) and [security boundaries](security.md) before running tasks.
